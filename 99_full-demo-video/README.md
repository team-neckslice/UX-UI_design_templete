## Releases에 올리는 방법

1. 저장소의 **Releases → Draft a new release**를 누릅니다.
2. 태그를 `demo-v1`처럼 만들고, 영상 파일(`playfit-demo_v1.mp4`)을 첨부합니다.
3. 게시한 뒤 파일 링크를 위 표에 적습니다.

스토리보드와 자막은 [storyboard.md](storyboard.md)를 봅니다.
