# 02 의뢰 작성

| 항목 | 내용 |
|---|---|
| 사용자 | 개발사(또는 기관 프로그램 담당자) |
| 목적 | 테스트 목적과 조건만 입력하면 10분 안에 의뢰를 마친다 |
| 사업계획서 근거 | 2-1 사용방법 2 "의뢰", 1-2 기능 "10분 의뢰 서식" |
| 이전 / 다음 | [← 01 테스터 프로필 등록](../01_tester-profile/) / [03 집단 제시·선택 →](../03_group-proposal/) |

## 담을 내용 체크리스트

- [ ] 테스트 목적(예: 튜토리얼 이해도, 난도, 버그)
- [ ] 필수 조건 / 선호 조건 구분
- [ ] 집단 구성(예: 장르 초보 6 + 경험자 6)
- [ ] 첫 경험 테스트 여부(해당 게임 미노출자만)
- [ ] 인원
- [ ] 일정
- [ ] 보상과 예상 비용(매칭료 + 테스터 보상)

## 데모 시나리오 메모

- 로그라이크 튜토리얼 테스트, 초보 6 + 경험자 6, 모두 첫 이용자, 60분
- 비용 표시: 매칭료 24만원 + 테스터 보상 18만원 = **42만원**
