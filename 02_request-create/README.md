# 02 의뢰 작성

| 항목 | 내용 |
|---|---|
| 사용자 | 개발사(또는 기관 프로그램 담당자) |
| 목적 | 테스트 목적과 조건만 입력하면 10분 안에 의뢰를 마친다 |
| 사업계획서 근거 | 2-1 사용방법 2 "의뢰", 1-2 기능 "10분 의뢰 서식" |
| 이전 / 다음 | [← 01 테스터 프로필 등록](../01_tester-profile/) / [03 집단 제시·선택 →](../03_group-proposal/) |

## 담을 내용 체크리스트

- [ ] 테스트 목적(예: 튜토리얼 이해도, 난도, 버그)
- [ ] 필수 조건 / 선호 조건 구분
- [ ] 집단 구성(예: 장르 초보 6 + 경험자 6)
- [ ] 첫 경험 테스트 여부(해당 게임 미노출자만)
- [ ] 인원
- [ ] 일정
- [ ] 보상과 예상 비용(매칭료 + 테스터 보상)

## 화면 구성

이 단계의 화면은 **HTML 파일 하나**에 모두 담고, 화면끼리는 버튼으로 이어지게 만듭니다.

| 항목 | 내용 |
|---|---|
| HTML 파일 | `prototypes/02_request-create_v1.html` |
| 포함 화면 | 0 / 5 |
| 상태 | ⬜ 미작업 |

### 포함 화면 체크

HTML에 넣은 화면은 "포함" 칸을 ✅로 바꾸고, 위 표의 포함 화면 수도 함께 고칩니다.

| 번호 | 화면 | 설명 | 포함 |
|---|---|---|---|
| 01 | 테스트 목적 | 목적 선택, 첫 경험 / 수정 확인 테스트 구분 | ⬜ |
| 02 | 조건 | 필수·선호 조건(장르 경험, 환경, 언어 등) | ⬜ |
| 03 | 집단 구성 | 집단별 인원 설정, 구성 비율 막대 | ⬜ |
| 04 | 일정·보상 | 테스트 기간, 플레이 시간, 보상, 예상 비용 | ⬜ |
| 05 | 확인·제출 | 입력 내용 요약, 비용 내역, 의뢰 제출 | ⬜ |

상태: ⬜ 미작업 · 🟨 작업 중 · ✅ 확정

## 데모 시나리오 메모

- 로그라이크 튜토리얼 테스트, 초보 6 + 경험자 6, 모두 첫 이용자, 60분
- 비용 표시: 매칭료 24만원 + 테스터 보상 18만원 = **42만원**
