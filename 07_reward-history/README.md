## 담을 내용 체크리스트

- [ ] 보상 지급 내역(1.5만원)
- [ ] 개발사에게 받은 평가
- [ ] 쌓인 참여 이력(완료 테스트 수, 완료율)
- [ ] 갱신된 프로필(해당 게임 노출 기록 추가)
- [ ] 다음 추천 테스트 안내
