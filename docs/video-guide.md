# 화면 녹화 가이드

사업계획서에 넣을 영상은 단계 영상(01~07)을 이어 붙여 만듭니다. 모두 같은 규칙으로 녹화해야 이어 붙였을 때 자연스럽습니다.

## 녹화 설정

| 항목 | 규칙 |
|---|---|
| 해상도 | 1920×1080 |
| 프레임 | 30fps |
| 형식 | MP4(H.264) |
| 길이 | 단계당 30초~1분 |
| 용량 | 단계 영상 50MB 이하 |
| 소리 | 녹음하지 않음(내레이션·배경음은 전체 영상 편집 때 넣음) |

## 녹화 전에

- 브라우저 확대 비율 100%, 북마크바·확장 프로그램 아이콘을 숨깁니다.
- 알림을 끄고, 마우스 커서는 기본 크기로 둡니다.
- 데모 시나리오([demo-flow.md](demo-flow.md))의 게임 이름, 테스터 이름, 숫자를 그대로 씁니다.

## 녹화할 때

- 단계 HTML을 첫 화면부터 열고, 버튼으로 화면을 넘기며 끊지 않고 이어서 녹화합니다.
- 각 화면은 핵심 내용이 읽히도록 2~3초 멈춥니다.
- 클릭할 곳은 커서를 먼저 옮긴 뒤 0.5초 기다렸다가 누릅니다.
- 입력은 미리 채워 두거나 천천히 입력합니다.

## 전체 영상 만들기

1. 단계 영상 01~07을 순서대로 이어 붙입니다.
2. 단계가 바뀔 때 "개발사" / "테스터" 자막을 넣어 누구의 화면인지 보여 줍니다.
3. [../99_full-demo-video/storyboard.md](../99_full-demo-video/storyboard.md)의 자막·내레이션을 넣습니다.
4. 완성본은 GitHub Releases에 올리고, `99_full-demo-video/README.md`에 링크와 타임코드를 적습니다.
