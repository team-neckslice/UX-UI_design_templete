# 04 참여 제안·수락

|---|---|
| 사용자 | 테스터 |
| 목적 | 자신에게 맞는 테스트 제안을 받고, 내용을 확인한 뒤 동의하고 수락한다 |
| 사업계획서 근거 | 2-1 사용방법 4 "참여", 위험 대응 "비밀유지계약(NDA)" |

## 담을 내용 체크리스트

- [ ] 테스트 내용(게임, 목적, 플레이 시간)
- [ ] 보상(60분 기준 1.5만원)
- [ ] 일정(참여 기간, 제출 마감)
- [ ] 동의 항목(비밀유지계약, 개인정보 제공 범위)
- [ ] 이 제안을 받은 이유(내 프로필의 어떤 조건이 맞았는지)
