## 담을 내용 체크리스트

- [ ] 테스트 내용(게임, 목적, 플레이 시간)
- [ ] 보상(60분 기준 1.5만원)
- [ ] 일정(참여 기간, 제출 마감)
- [ ] 동의 항목(비밀유지계약, 개인정보 제공 범위)
- [ ] 이 제안을 받은 이유(내 프로필의 어떤 조건이 맞았는지)

HTML에 넣은 화면은 "포함" 칸을 ✅로 바꾸고, 위 표의 포함 화면 수도 함께 고칩니다.

| 번호 | 화면 | 설명 | 포함 |
|---|---|---|---|
| 01 | 제안 알림 | 새 테스트 제안 알림 | ⬜ |

| 03 | 동의(NDA) | 동의 항목 체크, 전자서명 | ⬜ |
