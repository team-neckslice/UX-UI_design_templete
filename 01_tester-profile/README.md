# 01 테스터 프로필 등록

| 항목 | 내용 |
|---|---|
| 사용자 | 테스터 |
| 목적 | 게이머가 자신의 게임 경험·환경·일정을 등록해, 목적에 맞는 테스트에 매칭될 근거를 만든다 |
| 사업계획서 근거 | 2-1 사용방법 1 "테스터 등록", 핵심기능 "프로필 축", 차별성 "정확한 매칭" |
| 이전 / 다음 | 시작 / [02 의뢰 작성 →](../02_request-create/) |

## 담을 내용 체크리스트

- [ ] 플레이한 게임·장르
- [ ] 경험 수준(장르 초보 / 경험자, 실력·도달 경험)
- [ ] 플레이 환경(OS, 사양, 입력 장치, 언어)
- [ ] 참여 가능 일정
- [ ] Steam 연동(**선택** 항목임을 표시)
- [ ] 항목별 근거 수준 표시(자기기입 / 연동 확인 / 운영 확인)

- 이 테스터가 03 단계의 "초보 6명" 중 한 명으로 뽑히는 흐름으로 이어집니다.
