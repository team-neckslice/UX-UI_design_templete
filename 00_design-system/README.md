# 00 디자인 시스템

모든 단계 화면이 같은 컬러, 글꼴, 컴포넌트를 쓰도록 기준을 모아 둡니다. 값이 정해지면 아래 표의 "결정 필요"를 채워 주세요.

## 폴더

| 폴더 | 넣을 것 |
|---|---|
| `colors/` | 컬러 팔레트 이미지, 컬러 값 표 |
| `typography/` | 글꼴·크기·굵기 단계 이미지 |
| `components/` | 버튼, 칩, 카드, 입력창, 배지, 진행 표시 등 |

## 컬러

| 역할 | 값 | 쓰는 곳 |
|---|---|---|
| 메인 | 결정 필요 | 주요 버튼(CTA), 강조 |
| 보조 | 결정 필요 | 보조 버튼, 선택 상태 |
| 배경 | 결정 필요 | 페이지 배경, 카드 배경 |
| 텍스트 | 결정 필요 | 제목, 본문, 보조 텍스트 |
| 상태 | 결정 필요 | 성공(완료), 경고(미확인), 오류(불참) |

참고: 경쟁·참고 플랫폼 13곳 분석 결과 게임 테스트 서비스에서 보라 계열이 두 곳(gametester.app, Lysto)과 겹칩니다. 차별화하려면 보라는 피하는 편이 좋습니다(`platform_design_analysis_v3.md` 3단계 참고).
